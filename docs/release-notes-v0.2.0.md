# MIX-agent v0.2.0

初回のバージョン付きリリースです。Chat・Thinking・Agentを中心に、セルフホストで利用する機能を拡充しました。

## 主な追加・改善

- Providerプリセットを50種類に拡充し、モデル一覧・対応機能の確認、Auto候補の設定、Tool Callingの手動再確認に対応。
- Chat・Thinking・Agentで利用するToolの選択と実行方針を整理。長い作業向けのAgent実行ループとRun状態の記録を改善。
- 会話が長くなったときの文脈圧縮、Runごとの要約表示、最終回答の有無のチェックを追加。
- Knowledgeのテキスト登録と検索、Skillの登録・履歴・復元、定期実行に対応。
- Remote MCPのOAuth接続、運用診断、暗号化バックアップと復元処理を拡充。
- 会話のMarkdown書き出しと、対応環境でのWeb Push通知を追加。

## インストールと更新

- Docker Compose: READMEの手順に従い、更新前にデータをバックアップしてから新しいコードとイメージで起動してください。起動時にDB migrationが実行されます。
- ZimaOS: 公開後にコミュニティストアURLを追加できます。ストア版はAMD64向けで、Web UIはホストの8080番ポートを使います。
- ZimaOSのストア版と既存の手動Compose版は、インストール単位やデータの置き場所が異なる場合があります。既存データを引き継ぐ場合は、先にバックアップと復元手順を確認してください。バックアップには容量上限があり、パッケージキャッシュとBrowser Cookieは含まれません。

## 注意

初期開発版です。単一管理者が信頼できるLAN/VPN内で利用する想定で、インターネット公開は推奨しません。MCP管理用コンテナはDocker socketを使用します。ZimaOS版はPostgreSQLと複数のRunnerを起動するため、十分なメモリとディスク容量が必要です。
