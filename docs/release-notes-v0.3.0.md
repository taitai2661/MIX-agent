# MIX-agent v0.3.0

v0.2.3以降の完成済みコードを正式公開するリリースです。今回のmainブランチでは、アプリケーション実装を変更せず、バージョン情報と配布経路をv0.3.0に統一しています。

## 公開・配布

- Gitタグ `v0.3.0` とGitHub Release `MIX-agent v0.3.0` を公開します。
- 既存のGitHub Actionsにより、8種類のAMD64向けコンテナイメージをGHCRへ公開します。
- ZimaOSコミュニティストアのv2ストアと旧クライアント向けv1 `store/main.zip` をv0.3.0として配布します。

更新前に暗号化バックアップを取得してください。ZimaOSストア版と手動Compose版ではデータ領域が異なる場合があります。
