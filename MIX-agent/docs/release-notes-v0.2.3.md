# MIX-agent v0.2.3

v0.2.2からのパッチ更新です。

## 修正・改善

- ZimaOSなどLAN内のHTTPアクセスで `crypto.randomUUID()` が利用できない環境でも、初期管理者アカウントを作成できるようUUID生成をフォールバック対応しました。
- Web Crypto自体が利用できない環境でも、リクエスト識別用UUIDを生成してPOST処理を継続できるようにしました。
- Chatでストリーム接続が切れた後にRunが完了した場合、メッセージとTool実行履歴を再取得して表示を同期するよう改善しました。
- 添付ファイル選択をリセットし、同じファイルを続けて選択した場合でも再添付できるよう改善しました。
- Memoryの関連情報を、接続先の内容・状態を確認しながら辿れる表示へ改善しました。

## ZimaOS

- ZimaOSコミュニティストアの配布イメージを `v0.2.3` に更新します。
- v2ストアと旧クライアント向けv1 `store/main.zip` の両方を配布します。

更新前に暗号化バックアップを取得してください。ZimaOSストア版と手動Compose版ではデータ領域が異なる場合があります。
